Remaining optimization opportunities

Grouped by severity. Items marked broken confuse users today; gap means a missing feature; polish means refinement. Each lists a concrete fix and the file:line to touch.

P0 — fix broken / confusing UX first

P0

"Connect" from Recent Sessions doesn't actually connect (broken)

Clicking "Connect" on a recent connection (Main.qml:656-663) calls addSession() and switches to the new tab, but never loads the saved profile — the connection form stays empty, so nothing happens. The comment even admits it: "The SessionTab will load the history when its dialog opens" — but nothing opens a dialog.

Fix: when connecting from history, populate the new session's form fields (host, port, username, remote path) from the profile and trigger connect, or open the session tab pre-filled so the user only needs to enter the password.

P0

Manage Connections "Load" button does nothing (broken)

The "Load" button in the saved-connections dialog (Main.qml:184-189) only closes the dialog — the profile is never applied to any session.

Fix: wire "Load" to apply modelData to the active (or a new) session's connection form, matching the dropdown's existing loadConnectionProfile behavior.

P0

DeleteFoldersView.qml is orphaned/dead code

This view exists (qml/DeleteFoldersView.qml) but is never instantiated anywhere — qml contains no reference to it. The session stack only mounts FileExplorerView and DiskUsageView.qml. It also reaches into backend._settings (a private member), breaking encapsulation.

Fix: either wire it into the session stack (e.g. as a tab/tool) or remove it; if kept, route settings access through public backend slots instead of _settings.

P0

"Save passwords in history" checkbox is dead UI

The checkbox (Main.qml:275-279) is hard-coded checked: false with an empty onToggled — it does nothing and stores nothing.

Fix: wire it to settings persistence (or remove it if password persistence isn't implemented, to avoid false expectations).

P1 — important gaps

P1

Window geometry is never saved or restored (gap)

settings.py defines get_window_geometry() and save_window_geometry() but main.py never calls either, so the window always reopens at 1200×850 regardless of user resizing.

Fix: call save_window_geometry on closing/aboutToQuit, and apply saved geometry to the ApplicationWindow in Component.onCompleted.

P1

No keyboard submit for the connection form (gap)

Pressing Enter in the host/port/username/password fields does not connect; there's no "Connect on Enter" affordance, and no Ctrl+L focus for a path bar in the explorer.

Fix: bind Enter on the connection form fields to the connect action; add Ctrl+L to focus the explorer path bar.

P1

Inconsistent dialog modality (gap)

The download dialog is modal but the upload dialog is not (modal: false), so upload behavior differs from download for no clear reason.

Fix: make both file dialogs consistently modal (or both non-modal) FileExplorerView.qml.

P1

Toast notification is not theme-aware

The toast uses a hard-coded "#333333" background Main.qml:55 — fine on light, but a fixed mid-grey that doesn't adapt to the dark surface (#020617), so it looks off in dark theme.

Fix: derive the toast background from theme tokens like the rest of the app.

P1

Connection status dot overlaps tab text

The status dot is anchored to tabText.left Main.qml:360-370, so it renders on top of the "● "/"○ " prefix already drawn in the tab label — a visible duplication/overlap.

Fix: anchor the dot to the left of the tab content (before the text) or drop the dot since the label already carries the connected indicator.

P1

Theme "system" doesn't detect the system theme

The comment at Main.qml:23 says "system resolves to light for now" — picking System always yields a light app, even on a dark Windows.

Fix: implement real system-theme detection (query the OS theme via the backend or platform) so "System" follows Windows light/dark.

P1

No app version shown anywhere

The window title is just "Remote DeepZoom Folder Cleaner" Main.qml:14 with no version, making support and bug reports harder.

Fix: append the app version to the title and/or add an About dialog.

P1

Multi-select is checkbox-only

Selection works via checkboxes + Select All/None only — no Ctrl/Shift-click row selection, which power users expect in a file list.

Fix: add Ctrl+click / Shift+click row selection alongside checkboxes.

P2 — polish

P2

No empty-state guidance on the welcome screen

The welcome screen explains what the app does but not what the user needs (a Linux server, SSH access, credentials) — a first-time user has no hint of prerequisites.

Fix: add a short "What you need" hint box on the welcome screen.

P2

Generic empty-state text in the file list

"This folder is empty." is shown regardless of whether the folder is genuinely empty, the listing failed, or stats are still loading.

Fix: differentiate empty vs. error vs. loading states with distinct copy.

P2

"Show more" disabled silently for non-folders

The properties dialog's detail toggle is disabled for files with no explanation why.

Fix: add a small hint ("Folder stats only available for directories") when disabled FileExplorerView.qml properties dialog.

P2

Dialog sizes are inconsistent

Dialogs use mixed fixed widths (480/500/600px) with no shared sizing system.

Fix: standardize dialog widths by role (narrow / standard / wide).

P2

Tooltip delay is sluggish (600 ms)

ToolTip.delay: 600 Main.qml:408 makes hover labels feel slow.

Fix: reduce to ~300 ms app-wide.

P2

No "Disconnect" action once connected

There's no visible way to drop an SSH session short of closing the tab.

Fix: add a Disconnect button/action in the connected session tab.

P2

No About dialog

No app/version/license information is reachable from the UI.

Fix: add an About item (menu or Settings).

P2

Disk usage tables refresh only on demand

The mounted-filesystems and block-devices tables in DiskUsageView have refresh buttons but no auto-refresh, so usage numbers go stale.

Fix: add optional periodic refresh (pause when the view is inactive).

P2

Download cancel has no confirmation/feedback

Cancel aborts the SFTP transfer but the user gets no indication the transfer actually stopped.

Fix: show a toast when a download is cancelled.

P2

Duplicate manage-connections dialogs

SessionTab.qml defines its own manageConnectionsDialog alongside Main.qml's — duplicated UI.

Fix: consolidate to a single shared dialog.

P3 — minor / nit

P3

Toasts can't be dismissed manually

The toast auto-dismisses after 4 s but has no click-to-dismiss affordance Main.qml:51-95.

P3

Status bar lacks connection/disk info

The status bar doesn't show current connection state or disk usage at a glance.

P3

Path bar is not a breadcrumb

The folder path is a plain text field — no clickable parent-folder navigation.

P3

No inline size/folder count in file list rows

Row entries don't preview compressed stats inline.

Suggested implementation order

  1. P0: fix Recent Sessions "Connect" and Manage Connections "Load" so saved connections actually work — this is the app's primary onboarding path and it's broken today.
  2. P0: decide on DeleteFoldersView.qml — wire it in or remove it.
  3. P0: wire up or remove the "Save passwords in history" checkbox.
  4. P1: save/restore window geometry; Enter-to-connect; consistent dialog modality; theme-aware toast; fix status-dot overlap; real "System" theme detection.
  5. P2: welcome-screen guidance, differentiated empty states, disabled-toggle hint, dialog sizing, tooltip delay, Disconnect action, About dialog, disk-usage auto-refresh, cancel feedback, consolidate duplicate dialogs.
  6. P3: click-to-dismiss toast, status-bar info, breadcrumb path bar.
